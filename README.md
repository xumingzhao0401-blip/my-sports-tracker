# 🏃 运动记事本 Pro (Sports Tracker Pro)

一款基于 Flutter 开发的轻量级、无广告、纯本地存储的个人每日运动打卡与数据追踪 Android 应用。

不仅支持自定义运动项目、每日目标设定、紧凑表格化打卡，还内置了智能双周滚动日历与多维度趋势折线图，帮助你轻松记录和分析运动习惯。

---

## ✨ 核心功能特性

- 📅 **智能双周滚动日历**
  - **清晰月份/周数标注**：支持 ISO 8601 标准周数（如 `2026年 7月 (第31周)`）与跨月智能提示，解决跨月混淆问题。
  - **自动定位与回跳**：首次打开自动平滑定位至当前周，提供“回到今天”一键置顶功能。
  - **打卡状态可视化**：用 🟢 **全部完成**、🟠 **部分完成**、⚪ **未打卡** 图标直观展示每日完成情况。

- 📊 **高性能数据趋势图**
  - **按日 / 按周 维度切换**：底层采用纯 Canvas 绘制（`CustomPainter`），即便成百上千条记录也能流畅渲染。
  - **目标基线与刻度线**：直观展示历史运动量与每日目标线的差距，带除零保护与自动留白算法。

- ⚡ **极简高效打卡与流水明细**
  - **表格化紧凑布局**：在一行内融合项目名称、当日进度、编辑目标、趋势图与打卡按钮，单屏展示更多条目。
  - **快捷量按钮**：打卡弹窗内置 `+5`, `+10`, `+20`, `一键达标` 快捷输入按钮，提升单手打卡效率。
  - **流水记录管理**：支持查看与清空某一天的任意单条打卡明细。

- 🏃 **全生命周期运动项目管理**
  - 自由新增项目（指定名称、计量单位如“分钟/个”、每日目标）。
  - 长按项目卡片可安全二次确认删除，支持修改已有项目属性。

- 🔥 **统计看板与亮暗色状态**
  - 顶部看板实时显示 **今日完成进度** 与 **连续达标天数 (Streak)**。
  - 条目卡片根据今日是否达标自动切换高亮/沉静风格，方便快速识别。

- 💾 **离线本地持久化 (Privacy First)**
  - 基于 `shared_preferences` 实现 JSON 序列化存储，所有数据完全存放在手机本地，免去购买云服务器与网络隐私风险。

- ☁️ **零环境配置云端构建**
  - 完全不需要在本地部署庞大的 Android Studio 或 Flutter SDK。结合 **GitHub Codespaces** + **Codemagic**，直接在浏览器里写代码并免费编译出标准的 `.apk` 安装包。

---

## 🛠️ 技术栈与依赖

- **开发框架**：Flutter (Dart)
- **UI 设计**：Material Design 3
- **本地存储**：`shared_preferences: ^2.2.2`
- **图表绘制**：Flutter 原生 `CustomPainter`
- **构建打包**：Codemagic CI/CD (Android Release APK)
